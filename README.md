# Invoice Generator OD

A modern full-stack invoice and subscription management system built for **Ocean Developers LTD**. The application enables businesses to create professional invoices, manage customers, track subscriptions, generate PDF invoices, and view business insights from a central dashboard.

## ✨ Features

- Create and manage professional invoices
- Customer management
- Subscription management
- PDF invoice generation
- Dashboard with business analytics
- Reports and insights
- Company settings management
- Secure authentication

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Zustand
- React Router
- Recharts
- jsPDF

### Backend
- Node.js
- Express.js

### Database
- MySQL

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/junaid0x/Invoice-Generator-OD.git
```

### Install dependencies

```bash
# Client
cd client
npm install

# Server
cd ../server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` directory and configure your database credentials and application settings.

### Run the project

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
